## Included in this snapshot

This archive preserves the current English Landing Page, interactive workflow demonstration, theme, navigation, Partner and Workspace interface changes that were already present in the working directory, together with the new Proactive Workflow Phase 1 foundation.

The engine adds independent Case contracts, seven workflow states, five explainable task-oriented trigger types, per-Case memory, explicit inference confirmation, scheduled follow-up, Snooze/Dismiss, completion handling, source-revision invalidation, question limits and account-scoped local persistence. Existing official AI Partner IDs are retained. Workspace Insights and Coach handoff contracts are provided without live page integration or model calls.

The quotation fixture covers clarification, the raw missing-drawings reply, unconfirmed blocker extraction, explicit confirmation, a user-selected follow-up instant, reopening the stored workflow, and the received/still-waiting/snooze/dismiss outcomes. The original task is never modified by this workflow.

## Local archive and restore

The original checkout's `.git` directory is read-only in this managed session. The snapshot is therefore committed in an independent bare Git archive at `artifacts/aiask-current-20261118.git`, retaining the original commit history. The original checkout's Git metadata is not changed, so its normal Git status will continue to show working changes until it is synchronized in a writable local terminal.

The archive and exported bundle are local backup artifacts and are ignored by Git. They are not included in the uploaded source tree. `.env.local`, installed dependencies, build output, local logs, temporary caches and artifacts are also excluded. `.env.example` remains a template in the source repository.

The archive tag is the fixed reference for restoring this code version. The implementation and remaining boundaries are detailed in [Proactive Workflow Phase 1](../proactive-workflow-phase1.md).
